# dum-zabehlice-3d

Veřejná kopie 3D modelu domu (kontrolní model složený ze seznamu stěn a výkresů statiky, pracovní verze). Otevřít: https://ivantichy.github.io/dum-zabehlice-3d/

Zdroj a generátor jsou v soukromém repu dum-zabehlice (tools/model). Soubor index.html se přepisuje při každé nové verzi modelu.
